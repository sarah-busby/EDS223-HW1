# EDS 223 - HW 1
This repository contains materials for the first assignment for [EDS 223 - Geospatial Analysis & Remote Sensing](https://eds-223-geospatial.github.io/). Full instructions for this assignment can be found on [the course website](https://eds-223-geospatial.github.io/assignments/HW1.html). Per the instructions, this repo explores an environmental justice topic using the data from the United States Environmental Protection Agency’s previous [EJScreen: Environmental Justice Screening and Mapping Tool](https://www.epa.gov/ejscreen) and creates two maps to visualize the data. An unofficial recreation of EJScreen can be found [here](https://pedp-ejscreen.azurewebsites.net/).
